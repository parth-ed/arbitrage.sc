# SpreadNest

SpreadNest is a Vite + React web app that explains crypto arbitrage and provides a live scanner-style dashboard for cross-exchange signals.

## Features

- Warm, explanatory homepage for new users
- Live scanner view for arbitrage signals
- Signal history with average and peak arbitrage
- Responsive React UI built with TypeScript and Tailwind CSS

## Run locally

1. Install Node.js
2. Open PowerShell in this project folder
3. Install dependencies:

```sh
npm install
```

4. Start the development server:

```sh
npm run dev
```

5. Open the local URL shown in the terminal

## Build for production

```sh
npm run build
```

The production files will be created in `dist/`.

## Tech stack

- Vite
- React
